- 环境：项目内 `.venv`（managed Python 3.13.14），装 pandas 3.0.6 / xgboost 3.4.1 / sklearn 1.9.1 / streamlit 1.64（都是很新的大版本）。

- 方案：保留高缺失列、不手动 impute，用 XGBoost `enable_categorical=True` + `tree_method='hist'` 原生处理 NaN 和分类；修正了原 step4 的跨数据集 imputation bug。
- 训练指标（80/20 分层 split）：RainTomorrow ROC-AUC 0.904/F1 0.672；RainInTwoDays ROC-AUC 0.780/F1 0.510；MaxTempTomorrow MAE 1.95°C/R²0.857；MaxTempInTwoDays MAE 2.49°C/R²0.777。训练约 1.5 分钟。

## 关键坑（pandas 3.0 / xgboost 3.4）
- pandas 3.0 中 `pd.DataFrame([Series])` 不再保留 category dtype（塌缩成 str/float64）→ 传给 XGBoost 报 `DataFrame.dtypes ... must be int,float,bool or category`。修复：预测时直接传 DataFrame 切片（`df[mask]` 保留 dtype），不要 `iloc[0]` 后再 `pd.DataFrame([...])` 重建。
- 固定分类顺序用 `pd.CategoricalDtype(categories=...)`（风向16、季节4、站点49），保证训练/预测 category code 一致。
- pandas 3.0 弃用 `pd.api.types.is_categorical_dtype`（改 `isinstance(dtype, pd.CategoricalDtype)`）；streamlit 1.64 弃用 `use_container_width`（改 `width="stretch"`）；sklearn 弃用 `mean_squared_error(squared=False)`（改 `root_mean_squared_error`）。
- 运行：`.venv/Scripts/python.exe -m streamlit run app.py`（端口 8501）。
